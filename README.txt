KANJI STUDY PWA PACKAGE

Upload all files in this folder to the ROOT of a public HTTPS static website. Keep the filenames together. Then open the website URL on Android/iPhone to add it to the Home Screen.

GitHub Pages quick path: create a repository, upload these files to its root, open Settings > Pages, choose Deploy from a branch, select main and / (root), Save. Wait for the published HTTPS URL.

Android: open URL in Chrome > menu > Install app or Add to Home screen.
iPhone: open URL in Safari > Share > Add to Home Screen.

Note: service-worker offline caching works only when hosted over HTTPS (or localhost).
